# ⚡ TaskStream

> **Live task streaming with instant view switching, offline local storage, and native deadline reminders.**

TaskStream is a modern, high-performance Progressive Web App (PWA) built with React 18 and Vite. Designed around local-first privacy principles, it runs 100% offline with zero server dependencies or third-party tracking.

![TaskStream App Icon](./public/icon-192.png)

---

## ✨ Features

- **🗂️ Interactive Task Streaming**: Organize tasks into Work, Personal, Study, Health, Shopping, Ideas, Subscriptions, and Events categories.
- **▦ Multiple Workspace Views**: Switch seamlessly between **List**, **Kanban Drag-and-Drop Board**, and **Monthly Calendar** views.
- **☑️ Interactive Subtasks & Checklists**: Multi-item checklists inside task cards with live percentage progress tracking.
- **⚡ Quick Task Templates**: 1-click presets for *Weekly Review*, *Bill Payment*, *Workout Routine*, and *Study Sprint*.
- **🔔 Native Background Notifications**: Desktop & Mobile system alerts for 15-min deadline warnings, exact due times, overdue tasks, and subscription renewals.
- **📱 100% Offline PWA**: Built with Service Worker caching and Web App Manifest — installable directly on Android, iOS, and Desktop.
- **🏷️ Interactive Tag Cloud**: Filter your entire workspace by clicking dynamic hashtag pills (`#urgent`, `#meeting`).
- **🛡️ 100% Local & Private**: All data stays inside your browser's `localStorage`. No analytics, no accounts, no tracking.

## 🛠️ Built With

- **React 18** — Reactive component architecture

## 🚀 Getting Started

### Prerequisites
- Node.js `v18.0.0+`
- npm `v9.0.0+`

### Installation & Run

```bash
# Clone repository
git clone https://github.com/ghostbyte1014/TaskStream.git

# Navigate to project
cd TaskStream

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
